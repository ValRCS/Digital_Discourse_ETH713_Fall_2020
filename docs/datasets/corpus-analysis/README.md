# Synthetic media corpus

Created 2026-11-25 for DE0823. CC0 1.0 dedication. 24 invented short documents, 12 English and 12 Latvian, two fictional publications, two years, three genres. Six records per language/source pair; three per year. Not actual media discourse evidence or translations. The corpus is canonical here. Analyse one language at a time. No lemmatization is performed.
