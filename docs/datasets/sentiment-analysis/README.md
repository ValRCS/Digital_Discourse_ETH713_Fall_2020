# Week 07 instructional sentiment data

Created 2026-11-25 for RTU DE0823. All 48 texts, fictional publications, reference annotations and lexicon weights are synthetic teaching material released under CC0-1.0. No scraped articles, student data, empirical sentiment estimates or externally validated annotation are included. Each language contains six examples per reference class, three per class per source. Year and genre are illustrative metadata; filtering can yield small or empty subsets. English and Latvian examples are not parallel translations. Labels are author-intended interpretations, not independent gold-standard judgments. Targets are broad topic hints, not adjudicated spans. Mixed means evidence in both directions. Unclear is an algorithmic abstention, not a reference class. No recognized token means unclear, not neutral. Lexicons are tiny exact surface-form dictionaries, not validated NLP resources. Expected results describe this specific algorithm and fixture, not model accuracy on real discourse. The corpus is separate from the Week 06 corpus and uses compatible metadata.
