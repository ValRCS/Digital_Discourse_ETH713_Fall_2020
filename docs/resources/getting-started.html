Getting started

Use the website for concepts and notebooks for real Python execution.

Using Google Colab

  1. Open a notebook via the link on its lesson page.
  2. Read the Markdown explanation before running a code cell.
  3. Run cells in order; use Runtime → Run all when appropriate.
  4. Inspect output, errors and variable types. Save a personal copy if you want to edit.
  5. Download any output files you need to retain; runtime storage is temporary.

A Google account may be required for Colab execution or saving. No account is required to read this static website.
