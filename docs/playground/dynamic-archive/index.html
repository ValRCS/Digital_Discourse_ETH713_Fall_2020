Synthetic teaching archive · DE0823

Riga Digital Archive

A controlled JavaScript-driven website for practising web scraping and browser automation.

Teaching data only. Nine invented titles and metadata records, not a real archive. The initial HTML contains no records. JavaScript fetches a public JSON file when you load the collection, waits briefly and inserts articles into the DOM. Filters apply only to loaded records.

For researchers and students

Inspect View Source, Elements and Network. The public JSON teaching resource contains all nine records; retrieving it directly is deliberately permitted and simpler than browser automation when interaction is unnecessary. Search is case-insensitive substring matching, not lemmatization: Rīg matches Rīgā and Rīgas.
